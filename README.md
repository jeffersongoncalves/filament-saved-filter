# SavedFilter

Saved filters for Filament tables: save, share and restore filters, sort, search and column visibility as tabs or a dropdown, with presets, JSON export/import and multi-tenancy.

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/filament-saved-filter
```
